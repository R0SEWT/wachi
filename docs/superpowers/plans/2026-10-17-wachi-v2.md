# Wachi v2 — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que `wachi.rosewt.dev` pida rutas Rápida/Tranquila a una API propia que aplica los ADR 003 y 007-016 sobre el grafo peatonal OSM de Lima y los robos registrados a ≤ 150 m.

**Architecture:** Monorepo `api/` (FastAPI; grafo peatonal con Dijkstra de scipy, superficie S150 con cKDTree, regla de selección con tres umbrales) + `web/` (la PWA existente, que pasa de OSRM a `/api/route`). El motor se porta del script del experimento `comparacion_ruteo.py` del repo `wachi-research` (rama `exp/comparacion-ruteo`). Backend en la 4060 como servicio systemd de usuario expuesto con Tailscale Funnel; Netlify reenvía `/api/*`.

**Tech Stack:** Python 3.12, uv, FastAPI, pydantic-settings, numpy, scipy, shapely 2, pyproj, h3 v4, pyarrow, pandas, osmium (pyosmium), pytest, ruff. PWA en JS vanilla + Leaflet. systemd --user, Tailscale Funnel, Netlify.

**Spec:** `docs/superpowers/specs/2026-10-17-wachi-v2-design.md`

## Global Constraints

- Python `>=3.12`; gestor `uv`. Sin Docker ni `sudo` en el despliegue.
- Repo público `R0SEWT/wachi`, licencia MIT. El Wachi viejo ya se llama `R0SEWT/wachi-research` (clon local en `~/Code/freelance-externos/ElComercio/Wachi`).
- Sin metadata de IA en commits, PRs, issues ni READMEs (regla global). Nada de `Co-Authored-By`.
- Datos SIDPOL: `api/data/` va en `.gitignore`; los eventos solo viven en memoria; ningún endpoint devuelve coordenadas de denuncias.
- Parámetros exactos (config, env `WACHI_*`): `radius_m=150`, `step_m=20`, `h3_res=8`, `walk_kmh=5.0`, `betas=[0.5]`, `cap_pct=0.15`, `cap_min=5.0`, `gain_min=0.20`, `block_min_events=1.0`, `low_data_pct=10.0`, `snap_max_m=300.0`, `recinto_shrink_m=5.0`, bbox Lima `(S,W,N,E)=(-12.28,-77.13,-11.87,-76.85)`.
- Copy de la PWA: nunca "esquinas", "segura", "iluminada", "serenazgo", "bares". Beneficio = `+N min · pasa N cuadras menos junto a robos registrados`. Categoría = "robos y hurtos".
- Contrato `POST /route` exactamente como §6 de la spec: `fast` siempre, `calm` o `null`, `data_as_of`, `params`; errores 422 `fuera_de_cobertura` / `sin_via_peatonal_cerca` / `sin_ruta`, 503 `iniciando`.
- Geometría en `[lat, lon]`.
- El backend corre en la 4060 (WSL, alias ssh `4060`), que ya tiene Tailscale y Funnel activos; no quedan pasos con `sudo`.

## Review Focus

1. **Origen y destino que caen en el mismo nodo** (o a < 20 m): la ruta tiene 0 aristas; `fast` debe devolver geometría de 2 puntos iguales, `distance_m=0`, `calm=null`, sin excepción. → test en Task 7.
2. **Punto dentro del bbox pero en el mar o en un cerro sin vías** (p. ej. `-12.10, -77.12`): nodo más cercano a > 300 m → 422 `sin_via_peatonal_cerca` con `which`. → test en Task 7.
3. **Exposición de la Rápida igual a 0** (zona sin denuncias): la regla no debe dividir por cero; `calm=null` y `exposure_reduction_pct` no aparece. → test en Task 6.
4. **Ruta cuya Tranquila coincide arista por arista con la Rápida** (β=0,5 no cambia nada): `calm` debe ser `null`, no una copia. → test en Task 6.
5. **Parquet de eventos con filas sin fecha o fuera de la ventana**: `data_as_of` sale del máximo de `fecha` de lo cargado y las filas sin `lat/lon` se descartan sin romper. → test en Task 4.

Portado de `parse_osm` del experimento, dividido en lectura (`read_osm`) y construcción (`build_network`).

```python
"""Red peatonal de Lima a partir de OSM (ADR 013, 014)."""
from __future__ import annotations

import json
import re
import time
from dataclasses import dataclass, field
from pathlib import Path
from typing import Mapping

import numpy as np
import shapely
from scipy.sparse import csr_matrix
from scipy.sparse.csgraph import connected_components

from wachi.config import Settings
from wachi.geo import TO_UTM

# osmnx "walk" + busway/bus_stop (carril del Metropolitano y paraderos mapeados como vía)
_EXCL_HW = re.compile(r"abandoned|bus_guideway|busway|bus_stop|construction|cycleway|motor|no|planned|"
                      r"platform|proposed|raceway|razed")
_SIDEWALK_KEYS = ("sidewalk", "sidewalk:both", "sidewalk:left", "sidewalk:right")
_FOOT_OK = ("yes", "designated", "permissive")

Way = tuple[np.ndarray, np.ndarray, np.ndarray, str]
Poly = tuple[str, str, shapely.Geometry]


def walk_ok(t: Mapping[str, str]) -> bool:
    """Filtro tipo osmnx ``network_type='walk'`` + trunk sin acera y access=no."""
    hw = t.get("highway")
    if hw is None or t.get("area") == "yes" or _EXCL_HW.search(hw):
        return False
    foot = t.get("foot", "")
    if foot == "no" or t.get("service") == "private":
        return False
    if any(t.get(k) == "separate" for k in _SIDEWALK_KEYS):
        return False
    if t.get("access") in ("private", "no") and foot not in _FOOT_OK:
        return False
    if hw in ("trunk", "trunk_link"):
        has_sw = any(t.get(k) in ("yes", "both", "left", "right") for k in _SIDEWALK_KEYS)
        if not has_sw and foot not in _FOOT_OK:
            return False
    return True


@dataclass
class Network:
    u: np.ndarray           # nodo inicial de cada arista (0..N-1)
    v: np.ndarray
    length: np.ndarray      # m
    off: np.ndarray         # offsets en xy (len E+1)
    xy: np.ndarray          # UTM de todas las geometrías, concatenadas
    nxy: np.ndarray         # UTM de nodos
    polys: list[Poly]       # recintos (kind, name, geom UTM)
    hw: np.ndarray          # highway=* de cada arista
    stats: dict = field(default_factory=dict)

    def edge_xy(self, e: int, reverse: bool = False) -> np.ndarray:
        c = self.xy[self.off[e]:self.off[e + 1]]
        return c[::-1] if reverse else c


def read_osm(pbf: Path, bbox, recinto_tags) -> tuple[list[Way], list[Poly]]:
    import osmium

    S, W, N, E = bbox
    tags = [tuple(t) for t in recinto_tags]
    wkbf = osmium.geom.WKBFactory()
    fp = (osmium.FileProcessor(str(pbf)).with_locations()
          .with_areas(osmium.filter.TagFilter(*tags))
          .with_filter(osmium.filter.KeyFilter("highway", "amenity", "landuse")))
    ways: list[Way] = []
    polys: list[Poly] = []

    def inb(n):
        return n.location.valid() and S <= n.lat <= N and W <= n.lon <= E

    for o in fp:
        if o.is_way():
            if "highway" not in o.tags:
                continue
            ns = o.nodes
            if not (inb(ns[0]) or inb(ns[len(ns) - 1])):
                continue
            if not walk_ok(o.tags):
                continue
            ids, lo, la = [], [], []
            for n in ns:
                if n.location.valid():
                    ids.append(n.ref)
                    lo.append(n.lon)
                    la.append(n.lat)
            if len(ids) >= 2:
                ways.append((np.array(ids, np.int64), np.array(lo), np.array(la), o.tags.get("highway")))
        elif o.is_area():
            kind = next((f"{k}={v}" for k, v in tags if o.tags.get(k) == v), None)
            if kind is None:
                continue
            try:
                g = shapely.from_wkb(wkbf.create_multipolygon(o))
            except Exception:
                continue
            b = g.bounds
            if b[2] < W or b[0] > E or b[3] < S or b[1] > N:
                continue
            polys.append((kind, o.tags.get("name", ""),
                          shapely.transform(g, lambda c: np.c_[TO_UTM.transform(c[:, 0], c[:, 1])])))
    return ways, polys


def build_network(ways: list[Way], polys: list[Poly]) -> Network:
    """Corta las vías en nodos compartidos, proyecta a UTM y se queda con la componente mayor."""
    all_ids = np.concatenate([w[0] for w in ways])
    uniq, cnt = np.unique(all_ids, return_counts=True)
    multi = set(uniq[cnt >= 2].tolist())
    eu, ev, ehw, coords, off = [], [], [], [], [0]
    for ids, lo, la, hw in ways:
        cut = [0] + [i for i in range(1, len(ids) - 1) if int(ids[i]) in multi] + [len(ids) - 1]
        for a, b in zip(cut[:-1], cut[1:]):
            if ids[a] == ids[b] and b - a < 2:
                continue
            eu.append(ids[a])
            ev.append(ids[b])
            ehw.append(hw)
            coords.append(np.c_[lo[a:b + 1], la[a:b + 1]])
            off.append(off[-1] + b - a + 1)
    ll = np.concatenate(coords)
    x, y = TO_UTM.transform(ll[:, 0], ll[:, 1])
    xy = np.c_[x, y]
    off = np.array(off, np.int64)
    lines = shapely.linestrings(xy, indices=np.repeat(np.arange(len(eu)), np.diff(off)))
    length = shapely.length(lines)
    eu, ev = np.array(eu), np.array(ev)
    keep = (length > 0.5) & (eu != ev)
    node_ids, inv = np.unique(np.r_[eu, ev], return_inverse=True)
    ui, vi = inv[:len(eu)], inv[len(eu):]
    nxy = np.zeros((len(node_ids), 2))
    nxy[ui] = xy[off[:-1]]
    nxy[vi] = xy[off[1:] - 1]
    A = csr_matrix((np.ones(keep.sum()), (ui[keep], vi[keep])), shape=(len(node_ids),) * 2)
    _, lab = connected_components(A, directed=False)
    big = np.bincount(lab).argmax()
    keep &= lab[ui] == big
    old = np.flatnonzero(lab == big)
    remap = -np.ones(len(node_ids), np.int64)
    remap[old] = np.arange(len(old))
    sel = np.flatnonzero(keep)
    new_off, pieces = [0], []
    for e in sel:
        pieces.append(xy[off[e]:off[e + 1]])
        new_off.append(new_off[-1] + off[e + 1] - off[e])
    net = Network(u=remap[ui[sel]], v=remap[vi[sel]], length=length[sel],
                  off=np.array(new_off, np.int64), xy=np.concatenate(pieces), nxy=nxy[old],
                  polys=polys, hw=np.array(ehw)[sel])
    kinds: dict[str, int] = {}
    for k, _, _ in polys:
        kinds[k] = kinds.get(k, 0) + 1
    net.stats = {"vias_peatonales": len(ways), "nodos": int(len(old)), "aristas": int(len(sel)),
                 "km_red": float(net.length.sum() / 1000), "recintos": len(polys), "recintos_por_tipo": kinds}
    return net


def save_cache(net: Network, path: Path) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    np.savez(path, u=net.u, v=net.v, length=net.length, off=net.off, xy=net.xy, nxy=net.nxy, hw=net.hw,
             polys=np.array([(k, n, shapely.to_wkb(g)) for k, n, g in net.polys], dtype=object),
             stats=json.dumps(net.stats))


def load_cache(path: Path) -> Network:
    z = np.load(path, allow_pickle=True)
    polys = [(str(k), str(n), shapely.from_wkb(g)) for k, n, g in z["polys"]]
    return Network(z["u"], z["v"], z["length"], z["off"], z["xy"], z["nxy"], polys, z["hw"],
                   json.loads(str(z["stats"])))


def load_or_build(cfg: Settings) -> Network:
    if cfg.graph_cache.exists():
        return load_cache(cfg.graph_cache)
    t0 = time.time()
    ways, polys = read_osm(cfg.pbf_path, cfg.bbox, cfg.recinto_tags)
    net = build_network(ways, polys)
    net.stats["segundos_construccion"] = round(time.time() - t0)
    save_cache(net, cfg.graph_cache)
    return net
```

```python
"""Superficie de robos registrados a ≤ 150 m (ADR 016) y cobertura por celda H3 (ADR 010)."""
from __future__ import annotations

import hashlib
from dataclasses import dataclass
from pathlib import Path

import h3
import numpy as np
import pandas as pd
from scipy.spatial import cKDTree

from wachi.config import Settings
from wachi.geo import TO_LL, TO_UTM


def load_events(path: Path, sha256: str = "") -> pd.DataFrame:
    if sha256:
        digest = hashlib.sha256(path.read_bytes()).hexdigest()
        if digest != sha256:
            raise ValueError(f"sha256 de {path} no coincide: {digest[:12]}… ≠ {sha256[:12]}…")
    df = pd.read_parquet(path, columns=["lat", "lon", "fecha"])
    df = df.dropna(subset=["lat", "lon"]).reset_index(drop=True)
    df["fecha"] = pd.to_datetime(df["fecha"])
    return df


@dataclass
class Surface:
    tree: cKDTree
    s8: dict[str, int]
    data_as_of: str
    n_events: int
    low_threshold: float
    radius_m: float
    h3_res: int

    def at(self, x: np.ndarray, y: np.ndarray) -> dict:
        lon, lat = TO_LL.transform(x, y)
        cells = [h3.latlng_to_cell(a, b, self.h3_res) for a, b in zip(lat, lon)]
        s8 = np.fromiter((self.s8.get(c, 0) for c in cells), float, len(cells))
        s150 = self.tree.query_ball_point(np.c_[x, y], r=self.radius_m, return_length=True, workers=-1)
        return {"S8": s8, "S150": np.asarray(s150, float), "cells": cells}

    def is_low(self, cells: list[str]) -> np.ndarray:
        return np.fromiter((self.s8.get(c, 0) < self.low_threshold for c in cells), bool, len(cells))


def build_surface(df: pd.DataFrame, cfg: Settings) -> Surface:
    x, y = TO_UTM.transform(df.lon.values, df.lat.values)
    cells = pd.Series([h3.latlng_to_cell(a, b, cfg.h3_res) for a, b in zip(df.lat, df.lon)])
    s8 = {k: int(v) for k, v in cells.value_counts().items()}
    counts = np.array(list(s8.values()), float)
    low = float(np.percentile(counts, cfg.low_data_pct)) if len(counts) else 1.0
    low = max(low, 1.0)   # una celda sin ningún evento siempre es "pocos datos"
    data_as_of = pd.to_datetime(df.fecha).max().date().isoformat() if len(df) else ""
    return Surface(tree=cKDTree(np.c_[x, y]), s8=s8, data_as_of=data_as_of, n_events=int(len(df)),
                   low_threshold=low, radius_m=cfg.radius_m, h3_res=cfg.h3_res)
```

```python
"""Motor propio: Dijkstra sobre la red peatonal con costo largo·(1+β·r̄) (ADR 014)."""
from __future__ import annotations

import math
from dataclasses import dataclass

import numpy as np
import pandas as pd
import shapely
from scipy.sparse import csr_matrix
from scipy.sparse.csgraph import dijkstra
from scipy.spatial import cKDTree

from wachi.config import Settings
from wachi.geo import TO_LL, TO_UTM
from wachi.graph import Network
from wachi.surface import Surface


@dataclass
class Route:
    nodes: list[int]
    edges: list[int]
    xy: np.ndarray
    length_m: float


@dataclass
class Measure:
    length_m: float
    exposure: float
    cells: list[str]


class Router:
    def __init__(self, net: Network, surf: Surface, cfg: Settings):
        self.net, self.surf, self.cfg = net, surf, cfg
        E = len(net.u)
        lines = shapely.linestrings(net.xy, indices=np.repeat(np.arange(E), np.diff(net.off)))
        n = np.maximum(1, np.round(net.length / cfg.step_m)).astype(int)
        rep = np.repeat(np.arange(E), n)
        k = np.arange(len(rep)) - np.repeat(np.cumsum(n) - n, n)
        pos = (k + 0.5) * net.length[rep] / n[rep]
        pts = shapely.line_interpolate_point(lines[rep], pos)
        vals = surf.at(shapely.get_x(pts), shapely.get_y(pts))["S150"]
        self.p75 = max(float(np.percentile(vals, 75)), 1e-9)
        self.rbar = np.bincount(rep, vals, E) / n / self.p75
        # recintos: polígono dominante de cada arista (≥ 50 % de sus muestras dentro)
        self.shrunk = [g.buffer(-cfg.recinto_shrink_m) for _, _, g in net.polys]
        self.ptree = shapely.STRtree(self.shrunk)
        self.otree = shapely.STRtree([g for _, _, g in net.polys])
        self.edge_poly = -np.ones(E, np.int64)
        if net.polys:
            pi, gi = self.ptree.query(pts, predicate="within")
            first = pd.Series(gi, index=pi).groupby(level=0).first()
            samp_poly = -np.ones(len(rep), np.int64)
            samp_poly[first.index.values] = first.values
            df = pd.DataFrame({"e": rep, "p": samp_poly})
            inside = df[df.p >= 0].groupby(["e", "p"]).size().rename("k").reset_index()
            inside = inside.sort_values("k").drop_duplicates("e", keep="last")
            ok = inside.k.values >= 0.5 * n[inside.e.values]
            self.edge_poly[inside.e.values[ok]] = inside.p.values[ok]
        self.node_tree = cKDTree(net.nxy)
        self._csr: dict = {}

    def graph(self, beta: float, blocked: frozenset | None):
        key = (beta, blocked)
        if key in self._csr:
            return self._csr[key]
        net = self.net
        w = net.length * (1 + beta * self.rbar) if beta else net.length.copy()
        w = np.maximum(w, 1e-3)
        mask = np.ones(len(w), bool)
        if blocked:
            mask &= ~np.isin(self.edge_poly, list(blocked))
        e = np.flatnonzero(mask)
        uu, vv, ww, ee = np.r_[net.u[e], net.v[e]], np.r_[net.v[e], net.u[e]], np.r_[w[e], w[e]], np.r_[e, e]
        o = np.lexsort((ww, vv, uu))
        uu, vv, ww, ee = uu[o], vv[o], ww[o], ee[o]
        first = np.r_[True, (uu[1:] != uu[:-1]) | (vv[1:] != vv[:-1])]
        uu, vv, ww, ee = uu[first], vv[first], ww[first], ee[first]
        N = len(net.nxy)
        G = csr_matrix((ww, (uu, vv)), shape=(N, N))
        G.sort_indices()
        if len(self._csr) > 40:
            self._csr.pop(next(iter(self._csr)))
        self._csr[key] = (G, ee)
        return self._csr[key]

    def blocked_for(self, allowed: set[int]) -> frozenset:
        return frozenset(set(range(len(self.net.polys))) - allowed)

    def route(self, src: int, dst: int, beta: float, blocked: frozenset | None) -> Route | None:
        if src == dst:
            return Route([src], [], self.net.nxy[[src, src]].copy(), 0.0)
        G, ee = self.graph(beta, blocked)
        crow = float(np.hypot(*(self.net.nxy[src] - self.net.nxy[dst])))
        lim = 1.5 * crow + 1000
        while True:
            dist, pred = dijkstra(G, directed=True, indices=src, return_predecessors=True, limit=lim)
            if np.isfinite(dist[dst]) or lim > 2e5:
                break
            lim *= 2
        if not np.isfinite(dist[dst]):
            return None
        nodes = [dst]
        while nodes[-1] != src:
            nodes.append(int(pred[nodes[-1]]))
        nodes = nodes[::-1]
        edges, pieces = [], []
        for a, b in zip(nodes[:-1], nodes[1:]):
            lo, hi = G.indptr[a], G.indptr[a + 1]
            pos = lo + np.searchsorted(G.indices[lo:hi], b)
            e = int(ee[pos])
            edges.append(e)
            c = self.net.edge_xy(e, reverse=self.net.u[e] != a)
            pieces.append(c if not pieces else c[1:])
        return Route(nodes, edges, np.concatenate(pieces), float(self.net.length[edges].sum()))

    def measure(self, route: Route) -> Measure:
        vx, vy = route.xy[:, 0], route.xy[:, 1]
        cells = self.surf.at(vx, vy)["cells"]
        if route.length_m == 0:
            return Measure(0.0, 0.0, cells)
        line = shapely.linestrings(route.xy)
        L = float(shapely.length(line))
        n = max(1, math.ceil(L / self.cfg.step_m))
        starts = np.arange(n) * self.cfg.step_m
        seg = np.minimum(self.cfg.step_m, L - starts)
        pts = shapely.line_interpolate_point(line, starts + seg / 2)
        s150 = self.surf.at(shapely.get_x(pts), shapely.get_y(pts))["S150"]
        return Measure(L, float((s150 * seg / 1000).sum()), cells)

    def snap(self, lat: float, lon: float) -> tuple[int, float]:
        x, y = TO_UTM.transform(lon, lat)
        d, i = self.node_tree.query([x, y])
        return int(i), float(d)

    def node_ll(self, i: int) -> tuple[float, float]:
        lon, lat = TO_LL.transform(*self.net.nxy[i])
        return round(float(lat), 6), round(float(lon), 6)

    def allowed_polys(self, *nodes: int) -> set[int]:
        if not self.net.polys:
            return set()
        pts = shapely.points(self.net.nxy[list(nodes)])
        _, gi = self.otree.query(pts, predicate="within")
        return set(gi.tolist())
```

```python
"""Regla de selección (ADR 015): Rápida = más corta; Tranquila = menor exposición dentro del tope."""
from __future__ import annotations

from dataclasses import dataclass

from wachi.config import Settings
from wachi.router import Measure, Route


@dataclass
class Selection:
    fast: Route
    fast_m: Measure
    calm: Route | None
    calm_m: Measure | None
    reduction: float
    detour_m: float


def select(fast: Route, fast_m: Measure, cands: list[tuple[Route, Measure]], cfg: Settings) -> Selection:
    L0 = fast.length_m
    cap = min(L0 * (1 + cfg.cap_pct), L0 + cfg.cap_min * cfg.walk_m_per_min)
    ok = [(r, m) for r, m in cands if r.length_m <= cap + 1e-6 and r.edges != fast.edges]
    if not ok or fast_m.exposure <= 0:
        return Selection(fast, fast_m, None, None, 0.0, 0.0)
    calm, calm_m = min(ok, key=lambda rm: (round(rm[1].exposure, 6), round(rm[0].length_m, 3)))
    if calm_m.exposure > (1 - cfg.gain_min) * fast_m.exposure:
        return Selection(fast, fast_m, None, None, 0.0, 0.0)
    reduction = 1 - calm_m.exposure / fast_m.exposure
    return Selection(fast, fast_m, calm, calm_m, reduction, calm.length_m - L0)
```

```python
"""Presentación (ADR 011): beneficio en minutos y cuadras, tramos con pocos datos (ADR 010)."""
from __future__ import annotations

import numpy as np

from wachi.config import Settings
from wachi.geo import TO_LL
from wachi.router import Route, Router
from wachi.select import Selection


def blocks_near_robberies(route: Route, router: Router, cfg: Settings) -> int:
    """Cuadras (aristas) de la ruta con ≥ block_min_events robos registrados a 150 m, en promedio."""
    if not route.edges:
        return 0
    events_per_edge = router.rbar[route.edges] * router.p75
    return int((events_per_edge >= cfg.block_min_events).sum())


def low_data_segments(cells: list[str], surf) -> list[list[int]]:
    low = surf.is_low(cells)
    out, start = [], None
    for i, flag in enumerate(low):
        if flag and start is None:
            start = i
        if not flag and start is not None:
            out.append([start, i - 1])
            start = None
    if start is not None:
        out.append([start, len(low) - 1])
    return out


def _geometry(route: Route) -> list[list[float]]:
    lon, lat = TO_LL.transform(route.xy[:, 0], route.xy[:, 1])
    return [[round(float(a), 6), round(float(b), 6)] for a, b in zip(lat, lon)]


def _duration_s(length_m: float, cfg: Settings) -> int:
    return int(round(length_m / (cfg.walk_kmh * 1000 / 3600)))


def build_response(sel: Selection, router: Router, surf, cfg: Settings) -> dict:
    fast = {
        "geometry": _geometry(sel.fast),
        "distance_m": int(round(sel.fast.length_m)),
        "duration_s": _duration_s(sel.fast.length_m, cfg),
        "low_data_segments": low_data_segments(sel.fast_m.cells, surf),
    }
    calm = None
    if sel.calm is not None:
        fewer = blocks_near_robberies(sel.fast, router, cfg) - blocks_near_robberies(sel.calm, router, cfg)
        calm = {
            "geometry": _geometry(sel.calm),
            "distance_m": int(round(sel.calm.length_m)),
            "duration_s": _duration_s(sel.calm.length_m, cfg),
            "detour_m": int(round(sel.detour_m)),
            "detour_s": _duration_s(sel.detour_m, cfg),
            "exposure_reduction_pct": int(round(100 * sel.reduction)),
            "blocks_fewer_near_robberies": max(0, fewer),
            "low_data_segments": low_data_segments(sel.calm_m.cells, surf),
        }
    return {
        "fast": fast,
        "calm": calm,
        "data_as_of": surf.data_as_of,
        "params": {"cap_pct": cfg.cap_pct, "cap_min": cfg.cap_min, "gain_min": cfg.gain_min,
                   "radius_m": cfg.radius_m, "beta": cfg.betas[0]},
    }
```

```python
"""Une grafo, superficie y regla; es lo que la API llama."""
from __future__ import annotations

import logging
import time

from wachi.config import Settings
from wachi.explain import build_response
from wachi.graph import load_or_build
from wachi.router import Router
from wachi.select import select
from wachi.surface import Surface, build_surface, load_events

log = logging.getLogger("wachi")


class RouteError(Exception):
    def __init__(self, code: str, which: str | None = None):
        super().__init__(code)
        self.code, self.which = code, which


class Engine:
    def __init__(self, router: Router, surf: Surface, cfg: Settings):
        self.router, self.surf, self.cfg = router, surf, cfg

    def _snap(self, lat: float, lon: float, which: str) -> int:
        S, W, N, E = self.cfg.bbox
        if not (S <= lat <= N and W <= lon <= E):
            raise RouteError("fuera_de_cobertura")
        node, d = self.router.snap(lat, lon)
        if d > self.cfg.snap_max_m:
            raise RouteError("sin_via_peatonal_cerca", which)
        return node

    def route(self, origin: tuple[float, float], destination: tuple[float, float]) -> dict:
        a = self._snap(*origin, "origin")
        b = self._snap(*destination, "destination")
        blocked = self.router.blocked_for(self.router.allowed_polys(a, b))
        fast = self.router.route(a, b, 0.0, blocked)
        if fast is None:
            raise RouteError("sin_ruta")
        cands = []
        for beta in self.cfg.betas:
            r = self.router.route(a, b, beta, blocked)
            if r is not None:
                cands.append((r, self.router.measure(r)))
        sel = select(fast, self.router.measure(fast), cands, self.cfg)
        return build_response(sel, self.router, self.surf, self.cfg)


def load_engine(cfg: Settings) -> Engine:
    t0 = time.time()
    net = load_or_build(cfg)
    log.info("red: %s", net.stats)
    surf = build_surface(load_events(cfg.events_path, cfg.events_sha256), cfg)
    log.info("eventos: %d, data_as_of=%s, umbral pocos datos=%.1f", surf.n_events, surf.data_as_of,
             surf.low_threshold)
    router = Router(net, surf, cfg)
    log.info("motor listo en %.0fs (p75 S150 = %.2f)", time.time() - t0, router.p75)
    return Engine(router, surf, cfg)
```

```python
"""API HTTP de Wachi: POST /route y GET /health."""
from __future__ import annotations

import asyncio
import logging
from contextlib import asynccontextmanager

from fastapi import FastAPI, Request
from fastapi.middleware.cors import CORSMiddleware
from fastapi.responses import JSONResponse
from pydantic import BaseModel, Field

from wachi.config import Settings
from wachi.engine import Engine, RouteError, load_engine

logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(name)s | %(message)s")


class LatLon(BaseModel):
    lat: float = Field(..., ge=-90, le=90)
    lon: float = Field(..., ge=-180, le=180)


class RouteRequest(BaseModel):
    origin: LatLon
    destination: LatLon


def create_app(engine: Engine | None, cfg: Settings, load_on_start: bool = False) -> FastAPI:
    @asynccontextmanager
    async def lifespan(app: FastAPI):
        if load_on_start and app.state.engine is None:
            app.state.engine = await asyncio.to_thread(load_engine, cfg)
        yield

    app = FastAPI(title="Wachi API", version="2.0.0", lifespan=lifespan)
    app.state.engine = engine
    app.add_middleware(CORSMiddleware, allow_origins=cfg.cors_origins, allow_methods=["GET", "POST"],
                       allow_headers=["*"])

    @app.get("/health")
    async def health(request: Request):
        eng: Engine | None = request.app.state.engine
        if eng is None:
            return JSONResponse({"status": "iniciando"}, status_code=503)
        return {"status": "ok", "nodes": int(len(eng.router.net.nxy)), "events": eng.surf.n_events,
                "data_as_of": eng.surf.data_as_of}

    @app.post("/route")
    async def route(req: RouteRequest, request: Request):
        eng: Engine | None = request.app.state.engine
        if eng is None:
            return JSONResponse({"error": "iniciando"}, status_code=503)
        try:
            out = await asyncio.to_thread(eng.route, (req.origin.lat, req.origin.lon),
                                          (req.destination.lat, req.destination.lon))
        except RouteError as e:
            body = {"error": e.code}
            if e.which:
                body["which"] = e.which
            return JSONResponse(body, status_code=422)
        return out

    return app


app = create_app(None, Settings(), load_on_start=True)
```

```python
import hashlib
import sys
from pathlib import Path

from wachi.config import Settings
from wachi.graph import load_or_build


def sha(p: Path) -> str:
    h = hashlib.sha256()
    with p.open("rb") as f:
        for chunk in iter(lambda: f.read(1 << 20), b""):
            h.update(chunk)
    return h.hexdigest()


def main():
    cfg = Settings()
    for p in (cfg.pbf_path, cfg.events_path):
        if not p.exists():
            sys.exit(f"falta {p}")
    net = load_or_build(cfg)
    print("red:", net.stats)
    print(f"WACHI_PBF_SHA256={sha(cfg.pbf_path)}")
    print(f"WACHI_EVENTS_SHA256={sha(cfg.events_path)}")


if __name__ == "__main__":
    main()
```
